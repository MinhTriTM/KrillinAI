Cấu Hình LLM

Hướng Dẫn Sử Dụng

Hướng dẫn cấu hình LLM API (có thể sao chép văn bản)

1. API Base URL：

  • OpenAI chính thức：https://api.openai.com/v1
  • Alibaba Cloud Bailian：https://dashscope.aliyuncs.com/compatible-mode/v1
  • DeepSeek：https://api.deepseek.com/v1

2. API Key：

  • Lấy từ bảng điều khiển của nền tảng tương ứng
  • Vui lòng giữ cẩn thận, tránh rò rỉ

3. Tên mô hình：

  • OpenAI：gpt-3.5-turbo, gpt-4, gpt-4-turbo...
  • Alibaba Cloud：qwen-turbo, qwen-plus, qwen-max...
  • DeepSeek：deepseek-chat, deepseek-coder...

4. Khuyến nghị sử dụng：

  • Chọn mô hình phù hợp theo nhu cầu thực tế
  • Lưu ý chi phí gọi API
